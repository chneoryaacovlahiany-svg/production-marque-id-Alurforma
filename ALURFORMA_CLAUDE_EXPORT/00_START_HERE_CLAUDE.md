## Découpage cible sur 12 secondes

1. **0–2 s — Ouverture** : premières surfaces verre / lignes, apparition partielle du hero visual.
2. **2–4 s — Installation** : l'image principale commence à prendre toute sa place.
3. **4–6 s — Image principale** : hero visual clairement dominant, panneaux qui le cadrent et le révèlent.
4. **6–8 s — Accélération** : profondeur / tunnel / travelling, image encore intégrée dans les cadres.
5. **8–10 s — Convergence** : éléments graphiques se réunissent, préparation de la signature.
6. **10–12 s — Révélation** : logo ALURFORMA + tagline sur les impacts graves de fin.
